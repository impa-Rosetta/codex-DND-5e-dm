因此当前版本 **不是完整 M2，也不是完整可玩的 D&D 5e**。`character-options.json` 中的 `indexed_only` 项只是来源入口；任何未通过机械验证的项都由建卡脚本拒绝。玩家扩展包属于后续阶段，不在 M2 内。

一级选项清单已逐条固定 14 个种族／亚种、12 个职业及 3 个一级子职业入口，转录六种一级施法职业的戏法／一级法术列表，并索引野蛮人、战士、武僧、游荡者的起始装备与技能／工具分支，见[对账清单](level1-options-inventory.md)。其余职业装备、种族法术选择、逐个法术效果及其他一级选择尚未逐项完成，目录完整性验收仍未通过。
