# M2 实际覆盖与验收状态

更新：2026-10-13。此页记录实际代码，不把目录索引当成规则实现。M2 的完成门槛仍以 [`m1-m2-plan.md`](m1-m2-plan.md) 和[一级建卡规格](superpowers/specs/2026-10-13-srd51-character-creation-design.md)为准。

| 模块 | 当前状态 | 未完成的 M2 验收 |
| --- | --- | --- |
| 骰子 | `d20`、`NdS±N`、优势／劣势与原始点数；已有单元测试 | 与所有规则操作完整集成 |
| 一级建卡 | 普通人类＋战士＋侍僧；标准数组、27 点购点、可审计六组 `4d6`、确认后持久化 | 其他 SRD 种族／亚种、11 职业、背景自定义、全部起始装备与合法戏法／一级法术；当前战斗风格仅防御体现在 AC，其他风格不能宣称可用 |
| 战斗 | 先攻排序、基本武器攻击、自然 1／20、重击骰、临时 HP、攻击事件幂等 | 开战命令、移动／距离、动作和附赠动作、反应、死亡豁免、休息、所有一级职业特性与施法调度 |
| 存档 | 创建、事件序列、按操作 ID 幂等、落后快照重放、坏日志拒绝、公开投影 | 跨进程并发写锁、完整事件类型的机械校验、损坏快照从备份恢复、版本迁移 |
| Codex Skill | 入口和分流参考已建立，明确禁止对未实现规则猜数值 | 在新会话中完成真实全流程与触发验收；打包安装说明 |
| 只读面板 | 本机 HTTP、公开快照、事件更新、窄栏布局；HTTP 200／405／404 测试 | 真正的浏览器视觉验收、完整战斗与探索同步、断线场景回归 |
| 纵向冒险 | 原创旧磨坊开局文案和起始地点 | NPC 交谈→检定→地图揭示→战斗→退出／续档的完整端到端脚本 |

因此当前版本 **不是完整 M2，也不是完整可玩的 D&D 5e**。`character-options.json` 中的 `indexed_only` 项只是来源入口；任何未通过机械验证的项都由建卡脚本拒绝。玩家扩展包属于后续阶段，不在 M2 内。
