# 旧磨坊会话（开发版）

开放情境中的技能检定可用 `skill-check --skill <技能 ID> --dc <1–30> --reason <场景及 DC 依据>`。先向玩家说明检定依据，获得玩家行动声明后再掷骰；这一命令只记录结果，不自行揭示地图地点或写入叙事奖励。游侠在已进入林中岔路时，对偏好地形相关的熟练智力／感知技能检定额外加一次熟练加值；追踪已选哥布林或兽人时可附加 `--activity track --target-race goblin|orc`，获得优势。DM 应核对实际场景，不得凭玩家要求添加不适用的优势。

每个操作先生成 UUID；同一意图重试复用原操作 ID。先用 `python scripts/state.py load <战役目录>` 读取公开状态。玩家在聊天中声明行动，DM 不替玩家选择。以下命令都使用 `python scripts/session.py <战役目录> <命令> --operation-id <UUID>`；完整选项用 `--help` 查看。

玩家与 NPC 交谈可用 `declare --text <玩家原话>` 记录声明；DM 根据已确立事实回复，再用 `narrate --text <公开观察>` 保存可见叙述。不可把未发现地点或 DM 私密设定写进公开叙述。

旧磨坊路口的场景检定 ID 为 `find_forest_path`：事先告诉玩家这是感知（察觉）DC 12，成功会发现林中岔路，失败暂未找到。玩家决定调查时用 `check --challenge-id find_forest_path`，如规则有优势／劣势再加 `--mode advantage`／`disadvantage`。检定、骰值和地图发现写入同一事件；自然 1／20 不自动决定属性检定结果。发现后玩家选择前往，执行 `move --location-id forest_path`。

短休只能在非战斗时执行 `short-rest`，至少一小时不做剧烈活动。若玩家选择花费一颗生命骰，另加 `--spend-hit-die`；在掷骰前确认选择。第二春短休后恢复，狂暴次数不恢复。长休由玩家提出、DM 确认场景容许至少八小时不中断的休息后执行 `long-rest`；脚本拒绝战斗中、零生命值或上次长休开始后不足 24 小时的角色。固定一级战士与野蛮人路径会恢复全部生命值、最多一颗已花费生命骰及各自职业资源，并清除没有其他持续时间的临时生命值；战役时间推进八小时。脚本只验证机械条件，不能替 DM 判定睡眠环境和叙事中的中断。未实现的场景、物品奖励或家规机械效果不能用自由文本直接写入存档，明确说明限制。

每次会话结束复述已提交状态、待处理选择和战役目录。勿从未公开的 DM 笔记向面板发送信息。
