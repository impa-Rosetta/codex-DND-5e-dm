# 运行会话

每回合先读已提交状态 `python scripts/state.py load <战役目录>`。给玩家可观察的环境和选择；玩家也可提出列表外行动。检定前说明适用属性、技能、DC 和可能后果，再用 `python scripts/dice.py roll d20+N --purpose check` 掷骰，记录原始点数。骰子脚本只返回事实，不判断成功；DM 按 SRD 5.1 和事先说明的 DC 裁定。

当前仓库尚未将普通检定、交谈、地点发现和休息接入经过测试的高层事件命令。不要声称这些已能可靠改变存档或面板。可进行无机械变化的叙事演示；涉及奖励、HP、位置、资源或地图时明确提示开发版限制并暂停提交。

每次会话结束复述已提交状态、待处理选择和战役目录。勿从未公开的 DM 笔记向面板发送信息。
