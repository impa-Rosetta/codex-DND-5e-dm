# 旧磨坊遭遇战（开发版）

只有林中岔路的一对一哥布林遭遇经过纵向测试；完整 D&D 5e 战斗尚未实现。战斗操作使用 `python scripts/session.py <战役目录> <命令> --operation-id <UUID>`。角色与怪物数值都来自已提交角色卡和固定遭遇，不能传入自定义武器数值。

进入林中岔路且玩家准备应对后用 `start-combat`。输出的 `combat.combatants` 已按先攻排序；当前角色为 `turn_index` 项。DM 报告先攻原始骰和行动者，然后询问玩家行动；不替玩家决定攻击。攻击用 `attack --target-id <战斗者 ID>`，但只有紧邻目标的已验证近战攻击可用；脚本在同一事件中记录命中、伤害、临时生命值吸收及目标 HP。自然 1 自动未命中、自然 20 自动命中并双倍伤害骰。相同操作 ID 重试不重掷。

战士在自己回合可用 `second-wind` 消耗一次附赠动作，恢复 `1d10+1`，短休后可再次使用。完成回合后用 `advance`。角色降至 0 HP 时，脚本会判定是否受到即死伤害；否则在角色每个回合开始后使用 `death-save`，记录原始 d20、成功／失败次数，自然 1 算两次失败、自然 20 恢复 1 HP。三次成功后稳定、三次失败后死亡；未完成必要豁免不能跳过该回合。哥布林倒下、角色死亡或稳定无法继续行动时用 `end-combat`，公开记录胜负并可续档。

目前未实现对 0 HP 角色的后续攻击、急救、治疗、稳定后的苏醒计时、移动、遮蔽、反应、借机攻击、逃跑与其他职业能力。哥布林若要攻击已倒地角色，应明确暂停机械结算，不能把未实现的攻击当作自动失手；不得手改 JSON。零生命值角色不能继续普通行动。本死亡豁免路径仅经过固定遭遇测试，不能宣称全部 5e 伤亡规则已经覆盖。
