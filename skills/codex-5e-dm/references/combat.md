# 旧磨坊遭遇战（开发版）

只有林中岔路的一对一哥布林遭遇经过纵向测试；完整 D&D 5e 战斗尚未实现。战斗操作使用 `python scripts/session.py <战役目录> <命令> --operation-id <UUID>`。角色与怪物数值都来自已提交角色卡和固定遭遇，不能传入自定义武器数值。

进入林中岔路且玩家准备应对后用 `start-combat`。输出的 `combat.combatants` 已按先攻排序；当前角色为 `turn_index` 项。DM 报告先攻原始骰和行动者，然后询问玩家行动；不替玩家决定攻击。攻击用 `attack --target-id <战斗者 ID>`，但只有紧邻目标的已验证近战攻击可用；脚本在同一事件中记录命中、伤害、临时生命值吸收及目标 HP。自然 1 自动未命中、自然 20 自动命中并双倍伤害骰。相同操作 ID 重试不重掷。

当前固定遭遇的开阔 5 英尺方格支持玩家回合内移动。先让玩家声明逐格路径，再执行 `combat-move --path "[[x1,y1],[x2,y2]]"`；每一步必须相邻，不能穿过活着的哥布林所在格，移动上限取角色速度。`combat-action --action dash` 消耗动作并使本回合移动上限翻倍；`disengage` 消耗动作，之后本回合离开敌人触及范围不触发借机攻击；`dodge` 消耗动作，使可见敌人在自己下回合开始前的攻击检定承受劣势。先声明动作再执行移动；不得事后补报撤离。若玩家不撤离而离开哥布林 5 英尺触及范围，哥布林在离开前以反应进行一次借机攻击，骰值、HP、反应消耗与最终位置同属一条事件；被击至 0 HP 会停在原格。此动作由固定哥布林战术自动使用；其它敌人／地形、掩护、隐形或玩家借机攻击尚未实现。

战士在自己回合可用 `second-wind` 消耗一次附赠动作，恢复 `1d10+1`，短休后可再次使用。完成回合后用 `advance`。角色降至 0 HP 时，脚本会判定是否受到即死伤害；否则在角色每个回合开始后使用 `death-save`，记录原始 d20、成功／失败次数，自然 1 算两次失败、自然 20 恢复 1 HP。三次成功后稳定、三次失败后死亡；未完成必要豁免不能跳过该回合。哥布林近身攻击零生命值但尚未死亡的角色时，攻击有优势，命中即重击；有实际伤害则按暴击累计两次死亡豁免失败，达到生命值上限的单次伤害直接死亡。哥布林倒下、角色死亡或稳定无法继续行动时用 `end-combat`，公开记录胜负并可续档。稳定但零生命值且战斗已结束的角色，可用 `recover-stable` 审计一次 `1d4` 小时后自发恢复 1 HP；不能提前把稳定当成清醒。

目前未实现急救、治疗、哥布林主动移动、一般地形与遮蔽、玩家反应／借机攻击、逃跑与其他职业能力。零生命值角色不能继续普通行动。本死亡豁免路径仅经过固定遭遇测试，不能宣称全部 5e 伤亡规则已经覆盖。
