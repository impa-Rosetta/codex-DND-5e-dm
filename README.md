# Codex 5e DM

一款面向 Codex 的中文单人 D&D 第五版冒险 Skill。玩家在 Codex 聊天中声明行动，由 Codex 担任地下城主；本地脚本处理掷骰、数值与存档，侧边栏网页只读展示角色、探索地图和冒险记录。

项目目前处于**设计与规划阶段，尚不可游玩**。首版以 2014 年版 SRD 5.1 为规则基础，先完成单人游玩，再考虑由玩家创作、AI 审核的可选扩展包。项目不会复制参考项目的代码或界面。

M1 已开始：规则来源与覆盖范围、事件/存档契约已写成文档。`rules-index.json` 目前只有来源索引，**没有可执行的游戏规则或掷骰器**。

## 路线图

1. M1：SRD 5.1 规则来源、覆盖矩阵与事件/存档契约。
2. M2：掷骰、角色与存档脚本；可玩的单人冒险纵向版本及 Codex 侧边栏面板。
3. M3：补齐 SRD 5.1 的 1–20 级核心覆盖。
4. M4：测试、打磨与正式发布。
5. 后续：可选的玩家自定义扩展包。
